# Compact completed analysis results

These files are a compact subset of completed authoritative analyses, not the
full intermediate replay trees. Each file's original source ID, original hash,
public hash and any metadata-path derivative are recorded in
`provenance/completed_output_assets.json`. Numeric CSV cells are preserved;
changes only replace original machine path strings with public logical aliases.
Whole-run receipts can refer to additional outputs that are regenerated from the
five frozen prediction archives and are deliberately omitted here.

- `profile_postprocessing_run02`: 24 completed datasets, including 22 primary
  core/all-binding/both-cold sources and 2 decoder sources. Corrected paired macro
  associations are the `common_association/` sidecar, intersecting defined
  arm/baseline contexts separately in every draw.
- `profile_measurement_strata_run02`:72 source tables with exact-four-cell and
  censor-involving identified-D direction/joint-choice views. Primary all-identified
  results remain separate.
- `panel_growth_analysis`:authoritative canonical k=0..full acquisition and query
  comparisons. Growth association fields retain their original per-model
  marginal-context convention; they are not the corrected common-context paired
  association endpoint. Direction/choice plots preserve all declared orders.
- `decision_support`:four broad main rows plus 272 endpoint/domain support rows.
  Counts are based on eligible measured rectangle rows, not virtual geometry
  dimensions or independent replicates.

Historical source IDs are aliases to the original evidence graph, not private
filesystem dependencies. To regenerate full tables, follow the archive restore
and stage commands in the repository README. Generated outputs use `outputs/`;
this fixed compact subset stays separate for direct inspection and verification.
